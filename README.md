## 🟢 Easy (5)
1. Read a CSV file with pandas and print the first 5 rows.
2. Find the mean and median of a numeric column.
3. Filter rows where a column's value is greater than a given threshold.
4. Count missing (null) values in each column of a dataframe.
5. Write a function that reverses a string without using a built-in reverse method.

## 🔴 Hard (5)
1. Write a function to detect and handle outliers using the IQR method.
2. Merge two dataframes on a key column and handle mismatched/missing keys.
3. Use `groupby()` and `pivot_table()` to summarize sales by region and month.
4. Write a function to compute a 7-day rolling average of a time-series column.
5. Build a simple linear regression from scratch using only NumPy (no scikit-learn).

## 📚 Theory (3)
1. What's the difference between a Python list and a tuple?
2. What's the difference between `.loc[]` and `.iloc[]` in pandas?
3. Explain how a lambda function works, with an example.
